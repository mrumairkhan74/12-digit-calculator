# 12-Digit Desktop Calculator

A free online 12-digit desktop calculator with percentage, tax, markup, memory,
calculation history, Grand Total, dark mode and full keyboard support.

## Features
- 12-digit display
- + − × ÷ %
- TAX+ / TAX− with configurable rate
- MU (markup / margin)
- Memory: M+, M−, MR, MC
- Grand Total
- Calculation history
- Copy result
- Dark / light theme
- Keyboard support
- Mobile responsive

## Files
- `index.html` — markup
- `css/style.css` — styles
- `js/calculator.js` — calculator logic
